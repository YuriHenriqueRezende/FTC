## 🎯 Objetivo do projeto

Este repositório tem como objetivo **servir como guia técnico e estratégico** para equipes FTC,  
oferecendo **métodos organizados**, **exemplos práticos** e **boas práticas** que ajudem as equipes a:

- Planejar o robô com mais eficiência
- Estruturar rotinas de autônomo
- Otimizar o lançamento de artefatos
- Padronizar processos dentro da equipe

---

## 👥 Público-alvo

- Equipes FTC iniciantes
- Equipes FTC intermediárias
- Mentores e técnicos
- Integrantes das áreas de:
  - Programação
  - Mecânica
  - Estratégia

---

## 🧠 Métodos abordados

- Planejamento de autônomo
- Organização de rotinas
- Testes e validação
- Estratégias de pontuação
- Documentação técnica
- Padronização de código e processos.
